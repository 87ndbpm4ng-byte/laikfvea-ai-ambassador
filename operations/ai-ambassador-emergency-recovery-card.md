## Recovery steps

1. **Visitor is stuck**
   - Press **End Conversation**.
   - Confirm language selection appears.
   - Start again.

2. **Microphone is not working**
   - Use typing or Quick Questions.
   - Retry **Talk** once if appropriate.
   - Do not repeatedly trigger microphone permission prompts.

3. **Daniel/Emily image is unavailable**
   - Conversation can still continue using text and available voice controls.
   - Do not repeatedly restart the kiosk unless needed.

4. **Answer failed or network seems slow**
   - Retry the question once.
   - Use Product Explorer while waiting.

5. **Wi-Fi is unavailable**
   - Confirm the device connection.
   - Reconnect to the approved network.
   - Product Explorer may still be usable.
   - Send commercial questions directly to stand staff.

6. **Page or browser problem**
   - Return to the approved kiosk URL.
   - Confirm language selection appears.
   - Run one short product-question smoke test.

7. **Complete freeze**
   - Restart the browser.
   - If still frozen, restart the device.
   - Return to the approved URL and run one short smoke test.

8. **Still not working**
   - Stop visitor interaction on the kiosk.
   - Use staff/manual product presentation.
   - Contact the designated technical person.

Never promise prices, MOQ, OEM terms, samples, shipping, or follow-up through the kiosk.
